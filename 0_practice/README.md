# 练习记录

这里存放我学习《动手学深度学习》时编写的练习代码。

## 环境

- 系统：WSL
- Python：Python 3
- 深度学习框架：PyTorch
- 虚拟环境：项目根目录下的 `.venv/`

## 开始使用

在仓库根目录执行：

```bash
source .venv/bin/activate
```

确认当前使用的是虚拟环境中的 Python：

```bash
which python
python --version
```

安装基础依赖：

```bash
python -m pip install torch numpy pandas matplotlib jupyterlab
```

## 运行练习

在仓库根目录执行：

```bash
python 0_practice/ndarray_practice.py
```
